Frontend React Backend FastAPI SQLite DB

Frontend React (Vite + Tailwind CSS)

Pantallas y componentes clave:

  • LoginPage - Pantalla de login con animaciones
  • WelcomeOverlay - Overlay de bienvenida con fade-in, progress bar, checkmark
  • AuthProvider - Contexto de autenticación con token
  • apiFetch - Cliente fetch con manejo de errores
  • AuthShell - Shell que protege rutas

Comunicación: fetch(`${BASE}${path`) con proxy Vite /api → backend:8001

Backend FastAPI (Python)

Rutas principales:

EndpointDescripción
/auth/loginPOST - Login de usuario
/auth/meGET - Datos del usuario actual
/auth/registerPOST - Registro de nuevo usuario
/healthGET - Health check de la API
/public/eventsGET - Eventos públicos

Motor: uvicorn | Base de datos: SQLite (aiosqlite) | Puerto: 8001

Sin requiere PostgreSQL - funciona offline con dev.db

Base de Datos SQLite

Archivo: dev.db

Tablas principales:

  • users - email, password_hash, name, role, active
  • venues - nombre, capacidad, dirección
  • tickets - entradas por usuario/venue
  • ticket_status - estados (issued, voided, refunded, redeemed)

Online | Sin PostgreSQL requerido | Funciona en Windows nativo

Usuario seed: admin@bar.test / demo1234

Flujos de comunicación:

  • Frontend → Backend: fetch('/api/auth/login') (POST JSON)
  • Backend → DB: aiosqlite queries asíncronas
  • Backen→ Frontend: JSON { user, access_token }

🎬 Animaciones Implementadas

Todas las animaciones respetan prefers-reduced-motion:

  • cardIn: Fade-in + slide vertical en tarjeta login (0.6s)
  • checkPop: Icono checkmark que escala desde 0 a 1 (0.5s)
  • welcomeIn: Overlay bienvenida escala 0.9→1 (0.5s)
  • progressBar: Barra avanza al 92% (1.5s ease-out)
  • shake: Error banner shake en login fallido
  • Efecto focus: Inputs scale(1.02) al enfocar
